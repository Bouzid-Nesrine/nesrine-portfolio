Replace this folder with your real assets. Add your PDF as assets/Nesrine_Bouzidi_CV.pdf. Then replace YOUR_EMAIL_HERE@example.com in script.js and the social placeholder links in index.html.
PROFILE PHOTO
-------------
Place your preferred professional profile picture here:
assets/images/profile.jpg

Recommended: square portrait, at least 800x800 px. The website automatically falls back to the NB monogram until the photo is added.

PROJECT WEBSITE LINKS
---------------------
Open index.html and find each project card's data-site-url attribute:
data-site-url=""

Add the real URL only for projects that should show a "Visit Website ↗" button.
Leave it empty for projects without a public website.
